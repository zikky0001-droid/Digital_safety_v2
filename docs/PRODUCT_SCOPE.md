# Digital Safety product scope — free preview

## Shipped in the website project
- Platform-specific install guide and floating install button.
- Pros & Cons and platform capability table.
- Locally evaluated URL warning signs.
- Locally evaluated pasted-message checks for common scam tactics and embedded URLs; no message text is uploaded.
- Occasional in-app safety notes, shown when the dashboard is opened after an eight-hour interval; these are not background pushes or device scans.
- Browser extension package for user-triggered current-tab link review.
- Permission UI with notification/location prompts only after explicit action.
- Estimate and clear Digital Safety-managed cache entries; optional Median WebView cache API call.
- Educational article cards.

## Not shipped as a working security engine
- Antivirus signatures or a malware engine.
- Android installed-app scanning.
- A reliable eight-hour background scan scheduler.
- Live phishing/malware reputation service.
- Whole-device/system-wide junk cleaner.
- Windows/macOS installed-program scan.
- Call-log/SMS/caller-ID analysis.
- VPN, Wi-Fi analyzer, app lock or contact access.

## Product naming
Until the native scanning engine and its test results exist, use names such as “Digital Safety”, “Security Dashboard”, or “Link Checker Preview”. Do not market this build as equivalent to Avast One or say it protects against all malware.
